# Sources for chapter 14, "Models anyone can download"

Written 2026-11-24. The chapter was written by Claude, made by Anthropic, and is partly about Anthropic.

After this file was written, the coordinator reworded the chapter's sentences marked "wording stronger than source" or "not found" here to match their sources (for example "similar quality" for CAISI, "use" for Menlo, attributing the half-plan limit to SemiAnalysis). A row's chapter sentence may therefore differ slightly from the final page; the evidence column is current.

Split from a longer draft on 2026-11-24 (the second half became chapter 15; the pay-and-limits story is now chapters 15 and 16), then checked by blind readers and a fairness reader. The rows below were rewritten against the chapter's current prose.

Every page below was opened by a researcher on 2026-11-24 unless the row says otherwise. The
researchers' working notes were scratch files and are not kept, so each row carries its own
quotation, URL, page date and status. "Read" means 2026-11-24 for every row.

Status key: **verified** = a primary page (the company, regulator, data publisher or paper itself)
states it; **news report** = only a journalist's account; **calculation** = arithmetic on sourced
inputs; **analyst estimate**; **allegation** = court complaint; **author's reasoning** = the
chapter's inference or explanation, which no source states; **not found** = the research does not
support it; **wording stronger than source** = the source supports a weaker statement, and the row
says how.

Only sentences of the chapter's prose are listed. Footnotes are checked in the last section.
